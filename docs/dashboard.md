# Dashboard

## Goals

- Let a user find relevant jobs in under a minute.
- Surface AI-enriched tags and matching score.
- Make saved searches and applications first-class.

## Main views

- **Feed** — filterable list of jobs (location, remote, seniority, skills)
- **Job detail** — full description, enriched tags, apply action
- **Saved** — shortlisted jobs
- **Applications** — status tracking (applied / interview / offer / rejected)
- **Profile** — preferences that drive matching

## Non-functional

- Mobile-first responsive layout
- Accessible (WCAG AA target)
- p95 page load < 2 s on broadband
