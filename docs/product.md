# Product

## Vision

Aggregate job offers from multiple sources into a single, searchable, AI-enriched dashboard so candidates spend less time searching and more time applying to relevant roles.

## Target users

- Students and junior candidates looking for internships or first jobs
- Active job seekers tracking offers across multiple boards
- Career services teams that need a unified view of the market

## Value proposition

- One interface for many job sources
- AI-extracted skills, seniority, and remote-policy tags
- Personal matching score based on user profile

## Out of scope (for now)

- Recruiter-facing features
- Paid placement / boosted listings
